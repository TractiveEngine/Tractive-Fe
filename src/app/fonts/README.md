# Self-hosted fonts

`layout.tsx` loads Montserrat via `next/font/local` from this folder so builds
work offline / behind restricted networks and on Vercel without fetching from
Google Fonts.

- `montserrat-latin-variable.woff2` — Montserrat **variable** font, latin
  subset, weight axis 400–700. Loaded with `weight: "400 700"`.

This file must stay committed. It was extracted from Next's own font cache
(`.next/dev/static/media/`) generated by a prior `next/font/google` fetch; it
is the byte-identical Google Fonts latin subset. If it ever needs
regenerating, run a build/dev once on a network with Google Fonts access and
copy the latin subset `*-s.p.*.woff2` out of `.next/.../static/media/`.
